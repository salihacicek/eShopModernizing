# Yazılım Modernizasyonu: Legacy'den Cloud Native Mimariye Geçiş (eShopModernizing)

Bu repository, **Engineering Design II** dersi kapsamında geliştirilen yazılım modernizasyonu projesini içermektedir.

## 📌 Proje Hakkında
Geleneksel (Legacy) monolitik bir uygulamanın güncel bulut (Cloud) ve konteyner (Container) teknolojileri kullanılarak modernize edilmesi süreçleri araştırılmakta ve Microsoft'un `eShopModernizing` referans projesi üzerinden analizler yapılmaktadır.

## 👥 Takım Üyeleri
1. Meryem Ceyda Günel (Takım Kaptanı)
2. Tuğba Burgaz
3. Hatice Gedik
4. Saliha Çiçek
5. Hayrunnisa Karaca

## 📂 Klasör Yapısı
* `/docs` : TÜBİTAK 2209-B başvuru formu taslakları ve proje sunum içerikleri.
* `/research` : Literatür taraması, benzer araç analizi ve akademik kaynaklar.
* `/src` : Modernizasyon adımlarının test edileceği ve kod analizlerinin yapılacağı kaynak klasör.

## 🛠 Kullanılan Teknolojiler
* .NET / ASP.NET Core
* Docker (Konteynerleştirme)
* Cloud Architecture (Bulut Mimarisi)
* Microservices Migration Patterns
